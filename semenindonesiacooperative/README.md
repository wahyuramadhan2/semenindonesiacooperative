# SIC Homepage — versi mudah diedit

Proyek ini adalah **rebuild/redesign independen** untuk latihan. Ini bukan source code asli backend atau sistem internal SIC.

## Cara membuka
1. Ekstrak `sic-homepage-editable.zip`.
2. Buka folder hasil ekstraksi di VS Code.
3. Buka `index.html`.
4. Jalankan dengan ekstensi Live Server, atau buka `index.html` langsung di browser.
5. Pastikan internet aktif agar font dan foto hero eksternal dapat dimuat.

## File mana yang diedit?
- `index.html` — teks, menu, tautan, dan susunan section.
- `styles.css` — warna, ukuran, jarak, layout, responsif, dan foto hero.
- `script.js` — menu hamburger dan tahun copyright.

## Edit warna
Buka `styles.css`, cari bagian `:root` di paling atas. Ubah nilai `--color-blue`, `--color-red`, `--color-paper`, dan `--color-ink`.

## Ganti foto hero
Di `styles.css`, cari `.hero-image` dan ubah URL pada `background-image`.
Sebaiknya gunakan foto resmi yang memang boleh digunakan. Foto yang ada sekarang hanya ilustrasi sementara, bukan dokumentasi SIC.

## Catatan konten
Nama unit bisnis mengacu pada kategori di situs resmi SIC. Ringkasan deskripsi dan susunan halaman di sini adalah materi desain awal, bukan pengganti profil resmi. Verifikasi teks, sejarah, logo, dan foto sebelum dipublikasikan.
